# Proyecto de Minería de Datos

## Análisis de Productividad en el Trabajo Remoto

**Autora:** Daniela Padilla Solera

---

## 📌 Descripción

Este proyecto presenta un análisis de datos relacionado con la productividad laboral en entornos de trabajo remoto.

El análisis fue desarrollado utilizando **Python** y diferentes herramientas de análisis y visualización de datos. El objetivo es explorar las características de los empleados e identificar patrones relacionados con productividad, satisfacción laboral, salarios, burnout y horas trabajadas.

---

## 🎯 Objetivos

* Explorar y comprender el dataset utilizado.
* Realizar limpieza y preparación de los datos.
* Aplicar técnicas de análisis exploratorio de datos.
* Obtener métricas estadísticas relevantes.
* Identificar patrones y relaciones entre las variables.
* Representar los resultados mediante visualizaciones.

---

## 🛠️ Tecnologías utilizadas

* Python
* Pandas
* NumPy
* Matplotlib
* JupyterLab
* Anaconda

---

## 📊 Dataset

El proyecto utiliza el **Remote Work Productivity Dataset 2025**, obtenido de Kaggle.

El dataset contiene información relacionada con productividad laboral, salarios, satisfacción laboral, burnout y horas trabajadas.

---

## 🔎 Análisis realizado

Durante el proyecto se realizaron diferentes etapas:

1. Importación y exploración de datos.
2. Limpieza de datos.
3. Transformación y manipulación.
4. Análisis estadístico.
5. Análisis exploratorio.
6. Integración de datos mediante `merge()`.
7. Visualización de resultados.
8. Interpretación de hallazgos.

Entre las operaciones utilizadas se encuentran:

* `groupby()`
* `pivot_table()`
* `sort_values()`
* `merge()`
* Filtros y ordenamientos
* Cálculos estadísticos
* Gráficos de barras
* Histogramas
* Boxplots
* Gráficos circulares

---

## 📈 Principales resultados

El análisis permitió estudiar diferentes indicadores relacionados con la productividad de los empleados, entre ellos:

* Promedio de horas trabajadas.
* Mediana de salarios.
* Máxima productividad.
* Mínimas horas de sueño.
* Total de tareas completadas.
* Desviación estándar.

También se analizaron relaciones entre horas trabajadas, satisfacción laboral, burnout, salud mental y productividad.
